# AWS SAA-C03 CertPrep

A self-contained, offline-capable study app for the AWS Certified Solutions Architect – Associate (SAA-C03) exam: 957 practice questions, 26 topic notes, a 101-service glossary with recognition triggers, 15 architecture patterns, and confusable-service comparisons.

Live at: https://andreigvr1.github.io/aws-saa-c03-certprep/

`index.html` is a built artifact (data + UI in one file) — it isn't meant to be hand-edited here. Progress is saved locally in your browser (localStorage); nothing is sent anywhere.
